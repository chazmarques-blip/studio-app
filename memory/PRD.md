# StudioX - Product Requirements Document

## Original Problem Statement
StudioX is an end-to-end autonomous video creation platform for animated children's content (Pixar-style).

## Core Architecture
- **Frontend**: React + TailwindCSS + Shadcn UI
- **Backend**: FastAPI + Python
- **Database**: Supabase PostgreSQL
- **AI Services**: Gemini (keyframes), Claude Sonnet 4.5 (scene direction), OpenAI GPT-4o-mini (text), Sora 2 (video), ElevenLabs (TTS), Kling AI (video + V2A + Lip Sync)

## SORA 2 PIPELINE (Cinema Sequential Mode)
1. Dialogue Unified: `dubbed_text` = `dialogue` (single source of truth)
2. Scene Directors SEQUENTIAL: Each director receives prev_scene context
3. Keyframe: Only scene 1 gets Gemini keyframe; scenes 2+ use last frame
4. Sora 2 Video: Full prompt (dialogue FIRST, no truncation)
5. Cinema Sequential: Each clip generated sequentially, last frame extracted for next
6. FFmpeg Crossfade: 1s crossfade between clips
7. TTS Audio Overlay: ElevenLabs per character beat (12s/scene)
8. V2A Sonoplastia: BGM + SFX using scene music_mood/sfx_notes
9. Final Mix: TTS (vol 1.0) + V2A (vol 0.15) onto video

## Scene Continuity System (3 Layers)
- Layer 1 (Screenwriter): transition_from, transition_to, music_mood, sfx_notes
- Layer 2 (Director): Sequential with prev_scene context, audio atmosphere
- Layer 3 (Post-prod): FFmpeg xfade crossfade 1s between clips

## Pipeline Auto-Advance
- Screenwriter done → auto-starts Director Review → navigates to Director step
- Director Review runs in background (avoids K8s 60s timeout)
- Polling timeout increased to 10 min

## Custom Instruction for Regeneration (NEW - 2026-04-16)
- Textarea in storyboard zoom modal: user writes what to adjust before regenerating
- Instruction injected as `[USER INSTRUCTION - MUST FOLLOW]` into scene description
- Works for both storyboard panels and video scene regeneration
- Empty field = normal regeneration (backwards compatible)

## Dialogue Unification
- `dubbed_text` is the canonical source (generated by Director Review)
- `dialogue = dubbed_text` unified in: screenwriter, parallel_agents, director review, apply-fixes
- Frontend always shows `dubbed_text || dialogue`
